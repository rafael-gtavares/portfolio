# 🚀 Meu Portfólio Pessoal - Rafael Tavares

Bem-vindo ao repositório do meu portfólio! Este projeto foi desenvolvido para centralizar meus principais trabalhos como Desenvolvedor Front-end, focando em uma interface moderna, responsiva e com alta performance.

## 🛠️ Tecnologias Utilizadas
* **HTML5** (Semântico)
* **CSS3** (Módulos, Flexbox, Grid e Animações)
* **JavaScript Vanilla** (Assincronismo, Manipulação de DOM e LocalStorage)
* **FormSubmit** (Integração de formulário de contato)

## 📁 Estrutura de Arquivos
O projeto foi construído seguindo boas práticas de organização, dividindo o CSS em módulos para facilitar a manutenção:
* `header.css` / `home.css` / `about.css` / `projects.css` / `contact.css` / `footer.css`

## 🌟 Projetos em Destaque
1. **Mural de Pensamentos**: CRUD completo com consumo de API REST e filtragem dinâmica.
2. **Pauta do Dia**: Organizador de tarefas com persistência em LocalStorage e CSS Art.
3. **RT Imóveis**: Landing Page profissional (Protótipo Funcional) focada em UX para o setor imobiliário.

## 📱 Responsividade
O site foi totalmente otimizado para dispositivos móveis, incluindo um **Carrossel Infinito** na seção de projetos para uma experiência nativa em tablets e smartphones.
